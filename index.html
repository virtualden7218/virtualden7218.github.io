💡 What this tool does

Windows saves the last 25 items you copy. It also limits each item to 4 megabytes. These limits prevent you from keeping a long history of your work. This tool removes those restrictions. It works by adjusting the internal settings of your Windows clipboard system. You keep all your copied text and images as long as you need them.

⚙️ System Requirements

  • Windows 10 or Windows 11
  • Administrator access on your computer
  • PowerShell enabled

🛡️ Is this safe?

This tool uses simple commands to update Windows registry keys. It contains only standard PowerShell code. It does not install external applications or hidden software. You remain in control of your computer at all times. If you want to undo the changes, you can simply run the script again or reset your clipboard settings through the Windows Control Panel.

❓ Frequently Asked Questions

Does this tool run in the background? No. The script updates a setting one time and then closes. It does not stay in your system tray or consume memory.

Will Windows updates undo these changes? Sometimes, a major Windows update might reset your settings to the default state. If you notice your history clearing at 25 items again, simply run the script one more time.

Can I store unlimited data? While this tool removes the 25-item cap, your computer still needs free space to save information. Keeping a very large history might eventually use more storage on your hard drive.
